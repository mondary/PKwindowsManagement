Confidentialité / Privacy

29 septembre 2026 · September 29, 2026

La vitrine

Cette page de présentation fonctionne avec des fichiers locaux. Elle n’intègre ni outil de mesure d’audience, ni publicité, ni police distante. Seul votre choix de langue est enregistré dans le stockage local de votre navigateur. Le playground est une simulation et n’accède pas aux fenêtres de votre ordinateur.

Le serveur hébergeant ces fichiers peut conserver ses journaux d’accès habituels. Les liens GitHub et Ko-fi vous conduisent vers des services tiers appliquant leurs propres politiques.

L’application

L’app sauvegarde ses réglages dans les préférences macOS. Les exports JSON et les sauvegardes automatiques sont écrits dans le dossier que vous choisissez. Un dossier synchronisé, comme Google Drive, est ensuite pris en charge par le service correspondant.

Les permissions servent aux fonctions activées : Accessibilité pour gérer les fenêtres et raccourcis ; automatisation Finder pour certaines commandes ; Calendrier pour importer les événements journée entière. Big Year peut récupérer les vacances scolaires depuis une source en ligne. Les URLs, scripts et services que vous lancez peuvent établir leurs propres connexions.

Les captures de cette vitrine utilisent un jeu de données fictives, sans vos données personnelles. Pour poser une question : issues du projet.

The website

This product website runs from local files. It includes no analytics, advertising or remote fonts. Only your chosen language is stored in your browser’s local storage. The playground is a simulation and cannot access your computer’s windows.

The hosting server may keep ordinary access logs. GitHub and Ko-fi links lead to third-party services with their own policies.

The application

The app stores settings in macOS preferences. JSON exports and automatic backups are written to your selected folder. If this folder is synchronized, for example with Google Drive, the corresponding service handles that synchronization.

Permissions support the features you enable: Accessibility for windows and shortcuts, Finder automation for certain commands, and Calendar for importing all-day events. Big Year may fetch school holidays from an online source. URLs, scripts and services you launch may make their own connections.

This website’s captures use sample data, not personal data. For questions, use the project issue tracker.
