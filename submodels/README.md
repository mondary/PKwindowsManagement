# Submodels

Références produit et UI à cloner ou à suivre.

## Launchers
- `LaunchNext` - référence launchpad / app launcher macOS.
- `LaunchpadPlus` - launcher visuel avec grille d’apps.
- `Raycast` - recherche, commandes, utilitaires, vitesse.

## Shortcut tools
- `KeyboardCowboy` - gestion avancée de raccourcis, actions et automatisations.

## Use cases to copy
- Recherche app par nom.
- Recherche app par usage récent.
- Commandes système textuelles.
- Affichage du raccourci directement sur l’icône.
- Lancement clavier rapide.
