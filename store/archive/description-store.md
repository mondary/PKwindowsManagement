## Description longue

### FR

**PKwindowsManagement** est une app macOS en barre de menu pour gérer les fenêtres au clavier et lancer rapidement les applications installées. Pilotez vos fenêtres via les API d'accessibilité macOS et accédez à un Launchpad plein écran entièrement configurable.

#### ✨ Fonctionnalités clés
- **Snap des fenêtres actives** — moitiés, tiers, quarts et coins de l'écran, raccourcis personnalisables
- **Maximisation en masse** — `Tout maximiser`, `Tout maximiser (app active)` et `Carreler toutes les fenêtres` en grille
- **Déplacement entre écrans** — fenêtre vers l'écran suivant ou précédent
- **Launchpad plein écran** — recherche, navigation clavier, applications récentes, tri par nom, dernière utilisation ou couleur d'icône
- **Raccourcis globaux par application** — actifs partout sur macOS, avec distinction gauche/droite des modificateurs et support `Fn + Shift`
- **Gestionnaire de snippets** — scripts exécutables et URLs avec raccourcis globaux (`Archive` et `DL2desk` inclus par défaut)
- **Vue Big Year** — calendrier annuel plein écran : thèmes (Pastel, Catppuccin, Dracula, Poster bleu), jours fériés français, vacances scolaires zones A/B/C, anniversaires et événements personnalisés
- **Grille Launchpad par écran** — colonnes, lignes, taille d'icônes et espacements réglables, profils par moniteur
- **Sauvegarde automatique** — export JSON horodaté vers un dossier au choix (ex : Google Drive) à chaque modification des réglages
- **Ouverture multiple du Launchpad** — `Option + Espace`, coin actif ou clic sur l'icône menubar

### EN

**PKwindowsManagement** is a macOS menu bar app for keyboard-driven window management and fast application launching. Drive your windows through macOS Accessibility APIs and access a fully customizable full-screen Launchpad.

#### ✨ Key features
- **Active window snapping** — halves, thirds, quarters, and screen corners, with customizable shortcuts
- **Bulk maximizing** — `Maximize All Windows`, `Maximize All Windows (Current App)`, and `Tile All Windows` in a grid
- **Display switching** — move a window to the next or previous display
- **Full-screen Launchpad** — search, keyboard navigation, recent apps, sorting by name, last used, or icon color
- **Global per-app shortcuts** — work anywhere on macOS, with left/right modifier distinction and `Fn + Shift` support
- **Snippet manager** — executable scripts and URLs with global shortcuts (`Archive` and `DL2desk` included by default)
- **Big Year view** — full-screen year calendar: themes (Pastel, Catppuccin, Dracula, Blue Poster), French public holidays, school holiday zones A/B/C, birthdays, and custom events
- **Per-display Launchpad grid** — columns, rows, icon size, and spacing all adjustable, with per-monitor profiles
- **Automatic backup** — timestamped JSON export to a chosen folder (e.g. Google Drive) on every settings change
- **Multiple Launchpad entry points** — `Option + Space`, hot corner, or menu bar icon click
