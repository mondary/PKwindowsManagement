# Cleanroom Notes

LaunchNext is cloned under `submodules/LaunchNext` as an external reference only.

Its license is GPL-3, so PKwindowsManagement must not copy LaunchNext source code if this project is intended to remain MIT-compatible.

Allowed use:
- Product behavior reference.
- UX notes.
- Feature checklist.
- Independent implementation in this repository.

Disallowed use:
- Copying LaunchNext Swift files.
- Translating LaunchNext implementation line by line.
- Importing GPL source into `Sources/PKwindowsManagement`.
